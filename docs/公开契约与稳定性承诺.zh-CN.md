# 公开契约与稳定性承诺

本文档用于说明 `hongxunpan/eloquent-query-dsl` 当前阶段哪些内容属于**稳定公开契约**，哪些内容只属于**内部实现**。

当前仓库仍处于 **pre-1.0** 阶段，但从本文件开始，已文档化的公开能力会尽量保持稳定；若后续必须调整，将在 README / CHANGELOG / 迁移说明中显式说明。

---

## 1. 总原则

### 1.1 输入与输出边界

本包当前的稳定公开结果边界是：

- `QueryDsl::for(...)->from(...)->apply()`；
- `QueryDslResult`；
- `DslFilterValues`；
- `DslPaginationRequest`。

本包不会为了兼容某个业务项目，把 core 回退成 HTTP response、`{ page, list }` envelope 或 `QueryPaginationTrait` 心智；若业务项目需要这些结构，应在项目 adapter / service 层自行接回。

### 1.2 Internal 不承诺稳定

以下命名空间下的类默认都属于**内部运行时实现**：

- `HongXunPan\EloquentQueryDsl\Reader\*`
- `HongXunPan\EloquentQueryDsl\Apply\*`
- `HongXunPan\EloquentQueryDsl\Section\*`
- `HongXunPan\EloquentQueryDsl\Kernel\*`
- `HongXunPan\EloquentQueryDsl\Input\Internal\*`

这些类可能在后续版本中：

- 重命名；
- 移动目录；
- 合并或拆分；
- 修改构造器；
- 调整内部协作方式。

即使它们目前是 `public class`，也**不构成稳定扩展承诺**。

### 1.3 文档化公开面优先

并非所有 `public` 可见的方法都自动构成稳定契约。

只有本文件明确列出的内容，才视为当前阶段的公开稳定面；未列出的 `public` 方法，如果只是为了内部装配、测试或历史过渡而保留，不应被外部项目依赖。

---

## 2. 当前稳定公开契约

### 2.1 推荐入口

以下类属于当前稳定公开入口：

- `HongXunPan\EloquentQueryDsl\QueryDsl`
- `HongXunPan\EloquentQueryDsl\QueryDslResult`
- `HongXunPan\EloquentQueryDsl\Definition\DslQueryDefinition`
- `HongXunPan\EloquentQueryDsl\Input\DslInputMap`
- `HongXunPan\EloquentQueryDsl\Input\Contract\DslInputParser`
- `HongXunPan\EloquentQueryDsl\Filter\Contract\DslFilterNormalizer`
- `HongXunPan\EloquentQueryDsl\Filter\DslFilterValues`
- `HongXunPan\EloquentQueryDsl\Page\DslPaginationPolicy`
- `HongXunPan\EloquentQueryDsl\Page\DslPaginationRequest`

### 2.2 `QueryDsl` 的稳定职责

`QueryDsl` 是推荐主入口，稳定职责包括：

- 绑定 Eloquent `Builder` 与 `DslQueryDefinition`；
- 接收外部参数数组；
- 可选接入 `DslInputMap`；
- 可选接入自定义 `DslInputParser`；
- 可选接入 `DslFilterNormalizer`；
- 可选接入 `DslPaginationPolicy`；
- 应用 query section 到 Builder；
- 返回 `QueryDslResult`。

### 2.3 `DslQueryDefinition` 的稳定职责

`DslQueryDefinition` 负责声明“允许怎么查”，包括：

- 主实体名；
- relation 映射；
- search / filter / between / sort 字段开放清单；
- keyword search；
- derived search / filter；
- 默认排序与派生默认排序；
- strict / loose 模式。

字段、实体别名与 relation 名默认都走安全 identifier 校验。普通字段字符串不承接 raw SQL、表达式、JSON path、函数调用或多级路径。

### 2.4 输入映射契约

当前稳定公开的输入扩展面包括：

- `DslInputMap`：声明外部参数名映射；
- `DslInputParser`：完全自定义输入解析；
- `DefaultDslInputParser`：默认 parser，可处理 query 包裹结构、array / JSON object 与 flat 输入。

输入映射只解决“外部协议如何转成 Query DSL section”，不解决业务 validator、权限或响应格式。

### 2.5 Filter normalizer 契约

`DslFilterNormalizer` 是 shared core 与使用侧 validator / normalize 能力之间的中性接缝。

稳定语义：

- 输入：filter payload、字段规则、选项；
- 输出：`DslNormalizedFilterSet`；
- 失败：返回错误集合，由 shared core 转成 Query DSL 异常；
- 成功：提供归一化后的 filter item 与 normalized values。

本包不直接依赖业务项目 validator，也不把某个业务项目的中文错误 envelope 作为公开契约。

### 2.6 Pagination facts 契约

`DslPaginationPolicy` 与 `DslPaginationRequest` 只输出分页事实：

- `page`；
- `limit`；
- `export_limit`。

稳定默认策略：

- `defaultPage = 1`；
- `defaultLimit = 20`；
- `maxLimit = 100`；
- `maxExportLimit = 1000`；
- bool、float、非整数字符串不作为有效分页值。

本包不执行分页查询，不返回 `{ page, list }`。

## 3. 明确不属于稳定承诺的内容

以下内容不属于本包稳定公开契约：

- `QueryDslV2Kernel`：仅作为 internal 兼容入口保留；
- section applier 的构造细节；
- reader / apply / kernel 的内部协作方式；
- legacy smoke runner 的内部断言工具；
- 使用侧 filter normalizer 的具体 validator 实现；
- Eloquent paginate / count / cursor paginate 的执行方式；
- HTTP response、异常翻译、业务错误码；
- 资源权限、租户隔离、业务默认筛选；
- 业务字段开放清单。

---

## 4. 变更规则

1. 修改推荐公开入口时，必须同步 README、CHANGELOG 与本文件。
2. 修改 search / filter / sort / pagination 语义时，必须同步查询能力矩阵与 regression。
3. 新增 internal 类不自动构成 public API。
4. 若需要把 internal 能力提升为公开契约，必须先补文档和测试，再发布。
5. pre-1.0 阶段允许调整 API，但必须在 CHANGELOG 中说明迁移影响。
